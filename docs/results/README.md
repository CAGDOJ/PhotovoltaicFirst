# PV-First Results

Esta pasta é a fonte central de resultados do PV-First.

- `all.csv`: conjunto consolidado de execuções válidas.
- `latest.csv`: espelho do conjunto consolidado para compatibilidade.
- `RPVfirstDDMMAA.csv`: arquivo diário enviado pelo PC quando houver execução.

Somente execuções compatíveis com os perfis V50 dimensionados para cobertura PV total quando houver irradiância suficiente são incorporadas ao `all.csv`.
